# Start a new prototype or internal tool

This plugin is only the way in. The steps live in the shared core and change often, so always use the latest:

1. Run `curl -fsSL https://raw.githubusercontent.com/hansalbertisaksson/test-core/main/skills/start-prototype/SKILL.md` and follow those steps exactly. They replace this file.
2. If that fails, the person is probably offline. Say so in one line and stop.

Once the project exists, everything else (kickoff, building, checks, shipping) comes from the project's own `.core/`, which updates itself.
